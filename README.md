# Customer Churn Prediction Using Machine Learning

## 📌 Project Overview

Customer churn is one of the biggest challenges faced by businesses. This project aims to analyze customer behavior and predict whether a customer is likely to leave the service using machine learning techniques.

The project includes Exploratory Data Analysis (EDA), data preprocessing, model building, and performance evaluation using multiple classification algorithms.

---

## 🎯 Objectives

- Analyze customer churn patterns using EDA.
- Preprocess and prepare the dataset for machine learning.
- Build multiple classification models.
- Compare model performance using evaluation metrics.
- Predict customer churn accurately.

---

## 📂 Dataset

The dataset contains customer demographic information, service details, billing information, and customer churn status.

Target Variable:
- *Churn*
